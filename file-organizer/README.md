# ファイル整理アシスタント（Windows）

ファイルを**提案するだけ**で、勝手には消しません。判断はブラウザ上で行い、承認したものだけを実行します。

## 使い方
1. Python 3.10以上をインストールする
2. `start.bat` をダブルクリックする（ブラウザで http://127.0.0.1:5123 が開きます）
3. 「スキャン」→「① 判断する」→「② 実行する」の順に進める

## 判断の操作
- グループごとに「未判断を全部承認」「1件ずつ見る」「未判断を全部残す」を選ぶ
- 1件ずつ見るときのキー操作：`Enter` 提案どおり / `D` 退避（移動の提案でも消す側へ回す） / `K` 残す / `S` 後回し / `Z` 1つ戻る / `O` エクスプローラで表示 / `Esc` 一覧へ

## 安全のための仕組み
- 「② 実行する」を押すまで、ファイルには一切触れない
- 削除はせず、`%USERPROFILE%\FileOrganizer_Trash\<日時>\` へ元のフォルダ構成のまま移動する
- 「③ 履歴」から、実行した回ごとに元の場所へ戻せる
- スキャン後に変更されたファイルは実行しない
- 「残す」と判断したファイルは、更新されない限り次回から提案しない
- OneDrive の「オンラインのみ」ファイルはダウンロードしない（重複チェックの対象外）

## 提案ルール（`config.json` で変更できます）
| 確信度 | 内容 | 処理 |
|---|---|---|
| 高 | 重複ファイル（コピーっぽい名前・Downloads内・新しい方を退避） | 退避 |
| 高 | `.tmp` `.log` などの一時ファイル | 退避 |
| 高 | 90日以上前のインストーラー | 退避 |
| 中 | Downloads 内の90日以上前の圧縮ファイル | 退避 |
| 中 | Downloads・デスクトップの画像・PDFなど | `ドキュメント\整理済み\<種類>` へ移動 |
| 低 | 365日以上使っていないファイル | 退避 |

対象フォルダ・除外フォルダ（`exclude_dirs` / `exclude_paths`）・日数も `config.json` で変更できます。
