# 就活管理：Gカレンダー ⇄ Notion 同期

要件書：Notion「就活」ページ配下の「就活管理システム 要件定義」

## セットアップ（初回のみ・約10分）

### 1. Notion インテグレーションを作る
1. https://www.notion.so/profile/integrations →「新しいインテグレーション」
2. 種類「内部」、名前「就活同期」で作成 → **シークレット**をコピー
3. Notion で次の3つを開き、右上「…」→「接続」→「就活同期」を追加
   - 就活 ページ（予定DBを含む）
   - 企業マスター
   - 選考進捗

### 2. GAS プロジェクトを作る
1. https://script.google.com →「新しいプロジェクト」（名前：就活同期）
2. `gas/Code.gs` の中身を貼り付け
3. 左の「サービス +」→ **Google Calendar API** を追加
4. 歯車（プロジェクトの設定）
   - タイムゾーン：`(GMT+09:00) 東京`
   - スクリプト プロパティ：`NOTION_TOKEN` = 手順1のシークレット
5. 関数 `setup` を選んで「実行」→ 権限を許可

以後、10分ごとに自動同期されます。

## 同期ルール
- 対象：説明欄に `job.mynavi.jp` を含む予定 / タイトルに就活キーワード / 企業マスターの企業名 / `#就活`
- 関係ない予定を拾ったら Notion で「対象外」にチェック
- Gカレンダーで削除 → Notion は「キャンセル」
- 両方編集されたら新しい方を優先
- 終わった予定は自動で「完了」

## トラブル時
- 実行ログ：GAS の「実行数」
- 全件取り直し：`resetSyncState` を実行 → `sync` を実行
